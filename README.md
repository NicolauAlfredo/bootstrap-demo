# Bootstrap Demo

A responsive frontend landing page built with Bootstrap 5.

This project was created as part of my Bootstrap learning path, with focus on layout structure, responsive design, semantic HTML, accessibility and reusable Bootstrap components.

## Live Demo

[View the live project](https://nicolaualfredo.github.io/bootstrap-demo)

## Preview

Frontend Bootcamp landing page with responsive sections, navigation, cards, forms, modal and accordion components.

## Features

- Responsive fixed-top navigation
- Hero showcase section
- Newsletter subscription form
- Course option cards
- Learning sections
- FAQ accordion
- Instructor profile cards
- Contact section with form
- Enrollment modal
- Footer with back-to-top link
- Semantic HTML structure
- Basic accessibility improvements

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Git
- GitHub Pages

## Accessibility and Semantics

This project includes:

- Semantic page structure using `main`, `section`, `nav` and `footer`
- Skip link for keyboard users
- Accessible labels for forms and buttons
- Decorative icons hidden with `aria-hidden`
- `aria-label` and `aria-labelledby` where appropriate
- Descriptive alternative text for profile images
- Responsive layout for different screen sizes
